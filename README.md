# Chromeheart

**Chromeheart** is a 2D mobile platformer developed using Unity.

## Game Description
Chromeheart is a futuristic platformer where players explore cyberpunk environments, collect coins, avoid dangerous obstacles and reach the exit portal.

## Game Features
- 2D platformer gameplay
- Mobile touch controls
- Collectible coins
- Moving platforms
- Enemies and obstacles
- Pause menu
- Futuristic cyberpunk graphics

## Technologies
- Unity 6
- C#
- Git
- GitHub

## Platform
iOS / Android
